## 🎯 Overview

This is a comprehensive LMS platform that enables teachers and students to interact in an educational environment. Teachers can create and manage assignments, while students can view assignments, submit work, and track their scores. The system provides a complete academic management workflow including course management, student enrollment, and performance tracking.

## 🛠 Tech Stack

### Backend

- **Runtime:** Node.js
- **Framework:** Express.js (v4.21.2)
- **Database:** MongoDB with Mongoose (v8.13.0)
- **Additional Libraries:**
  - `cors` - Cross-Origin Resource Sharing
  - `multer` - File upload handling
  - `morgan` - HTTP request logging
  - `body-parser` - Request body parsing
  - `@faker-js/faker` - Test data generation
  - `nodemon` - Development server auto-restart

### Frontend

- **Library:** React (v19.0.0)
- **Bundler:** Vite (v6.2.0)
- **Styling:** Tailwind CSS (v4.0.7)
- **Routing:** React Router DOM (v6.29.0)
- **HTTP Client:** Axios
- **UI Components:**
  - FontAwesome Icons (@fortawesome packages)
  - Framer Motion - Animations
  - React PDF - PDF viewer
  - React Markdown - Markdown rendering
- **Data Processing:** XLSX (Excel support)

## ✨ Features

### Student Features

- **Dashboard** - View home, profile, and rankings
- **Assignment Management** - View and browse assignments
- **Score Tracking** - Monitor individual and overall scores
- **Transcripts** - View detailed academic transcripts
- **Announcements** - Receive class announcements
- **Course Enrollment** - Access enrolled courses

### Teacher Features

- **Assignment Creation** - Create and manage assignments
- **Question Management** - Add and organize questions for assignments
- **Score Management** - Grade assignments and record scores
- **Student Management** - Manage student records and progress
- **Subject Management** - Organize course content by subjects
- **Assignment-Subject Linking** - Associate assignments with subjects

### General Features

- **User Authentication** - Student and teacher role-based system
- **Course Management** - Organize academic structure
- **School/Institution Setup** - Support for multiple schools
- **File Upload** - Support for uploading files (images, documents)
- **PDF Support** - View and process PDF files
- **Data Export** - Export data to Excel format
- **Search & Filter** - Find assignments and content quickly
- **Pagination** - Handle large datasets efficiently
